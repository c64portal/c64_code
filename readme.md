
# C64 Code repository

This repo contains code for my various Commodore 64 releases - mainly demoscene.
Waht you can find here so far:

- MD Invite Intro - C (kickC) source code and resources of the small invitation intro for Moonshine Dragons C64 party
- Censor Intro - censor_intro/readme.md -  C (Oscar64) src code for Censor Design intro I made for a compo

# Purpose and copyrights 

This source code is realesed for educational purposes of how to use KickC (mixed with some assembly code) to create little C64 productions like this one.
